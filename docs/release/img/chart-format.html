Tuning: whole-number semitone offsets, -24 to 24. Pitch = standard open MIDI note + tuning offset + fret.

Package and chart container

If any arrangement is extended: PSXR magic and <name>_rsxr_p.psarc.

PSXR packagePlain, unencrypted PSARC
→
Manifest JSON + HSANEach extended arrangement: "ExtendedRange": {"Version": 1} and exactly N positional tuning keys.
Other contentStock audio, art, vocals and showlights

Each extended SNG: plain wrapper, flags 1 (zlib), zeroed unused IV/signature slots and the complete uncompressed size.

SNXR headerVersion, instrument, N, reserved zero
→
Body in stock section orderN-wide chord templates and ChordNotes; positional note indices, section bits and N tuning entries
→
Zero paddingAfter MetaData, inside zlib

Compress header, body and padding together. Include all three in the uncompressed size. Use the specification's padding formula. No trailing extension block.

Mixed packages: six-string guitar and four-string bass keep stock manifests and charts. Stock-only packages keep PSAR magic and <name>_p.psarc.

Anchors, hand shapes, phrases, beats and tonesStock format

XML compatibility: include at least string0 through string5, unused values zero. Five-string bass XML has six tuning attributes; its native chart and manifest have exactly five entries.

5

Validate before sharing

AgreementInstrument, count and tuning match XML, chart, manifest and HSAN.
All N stringsNotes, chords, techniques, section bits and generated difficulties.
Complete bodyHeader, widths, counts and padding follow the specification.
Play testTuner, lanes, chords and scoring, then a stock control.

Without the XML marker, read as stock. Reject unknown versions, unsupported counts and invalid indices. A file name or strings attribute alone does not select extended mode.
